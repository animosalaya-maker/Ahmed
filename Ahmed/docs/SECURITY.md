# الأمان

## ما هو مُطبّق الآن

| الحماية | ماذا تمنع | أين |
|---|---|---|
| الخادم هو الحَكَم | اللاعب لا يقدر يغيّر مكانه أو صحته أو سرعته بتعديل اللعبة | `server/src/game/match.ts` |
| فحص صارم لكل رسالة | أي حقل زائد أو رقم خارج الحدود يُرفض (مثلاً `hp: 9999`) | `shared/src/protocol.ts` |
| حد لحجم الرسالة (2 كيلوبايت) | إرسال رسائل ضخمة لإسقاط الخادم | `server/src/server.ts` |
| حد لعدد الرسائل (60 بالثانية) | إغراق الخادم بالرسائل | `server/src/security/rateLimit.ts` |
| طرد بعد 20 مخالفة | لاعب يرسل رسائل سيئة باستمرار | `server/src/server.ts` |
| 4 اتصالات كحد أقصى لكل جهاز (IP) | فتح مئات الاتصالات من جهاز واحد | `server/src/security/rateLimit.ts` |
| السماح لمواقع محددة فقط (Origin) | مواقع أخرى تستخدم خادمك | `ALLOWED_ORIGINS` |
| تنظيف الأسماء | أسماء فيها أكواد أو حروف مخفية تقلب النص | `server/src/security/sanitize.ts` |
| مهلة 5 ثوانٍ للدخول، وفحص الاتصال كل 10 ثوانٍ | اتصالات معلّقة تستهلك الخادم | `server/src/server.ts` |
| رفض الأرقام القديمة أو المكررة (seq) | إعادة إرسال أوامر قديمة | `server/src/game/match.ts` |
| رؤوس أمان HTTP و CSP | حقن سكربتات وتضمين الصفحة في مواقع أخرى | `server/src/server.ts`، `client/index.html` |
| لا أسرار في الكود | تسريب كلمات المرور والمفاتيح | `.env` ممنوع من GitHub عبر `.gitignore` |
| نسخ مكتبات مثبتة، وفحص الثغرات | مكتبات فيها ثغرات معروفة | `package-lock.json`، فحص تلقائي في GitHub |

## قواعد عند الإضافة

- **لا تثق بأي شيء يرسله اللاعب.** الإصابة والقتل والغنائم يحسبها الخادم فقط.
- **لا ترفع ملف `.env`** ولا أي مفتاح أو كلمة سر إلى GitHub.
- عند النشر استخدم `wss://` (اتصال مشفّر) وليس `ws://`.
- شغّل `npm audit` قبل كل نشر.

## لاحقاً

- حسابات وتسجيل دخول، مع تخزين كلمات المرور مشفّرة.
- كشف الغش: سرعة تصويب غير طبيعية، إطلاق أسرع من السلاح.
- حظر اللاعبين والإبلاغ عنهم.
