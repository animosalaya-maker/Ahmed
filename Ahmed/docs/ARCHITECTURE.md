# بنية المشروع

```
Ahmed/
├── shared/      قواعد مشتركة بين اللعبة والخادم: أنواع الرسائل، الحدود، الثوابت
├── server/      خادم اللعب الجماعي (Node.js + WebSocket)
├── client/      اللعبة في المتصفح (Three.js + Vite)
├── assets/      الشخصيات والخرائط والأسلحة والأصوات
├── docs/        الشرح
└── prototype-2d/ النسخة الأولى 2D (للتجربة فقط)
```

## كيف تعمل اللعبة أونلاين

1. اللاعب يفتح اللعبة في المتصفح، فتتصل بالخادم عبر `/play`.
2. ترسل اللعبة `hello` فيها اسم اللاعب.
3. الخادم يعطيه معرّفاً ويضعه في فريق (2 إلى 4 لاعبين).
4. اللعبة ترسل **الأزرار التي يضغطها اللاعب فقط** 30 مرة في الثانية: حركة، اتجاه النظر، ركض، قفز، إطلاق.
5. الخادم يحسب كل شيء: مكان اللاعب، سرعته، صحته. ثم يرسل الحالة لكل اللاعبين 20 مرة في الثانية.

هذا اسمه **"الخادم هو الحَكَم" (server-authoritative)**. هو أهم أساس ضد الغش في ألعاب الإطلاق مثل Warzone.

## ما هو جاهز وما هو لاحقاً

| الجزء | الحالة |
|---|---|
| الخادم، الاتصال، الفرق، الحركة، الحماية | ✅ جاهز |
| محرك 3D في المتصفح (كاميرا، إضاءة، أرض مؤقتة) | ✅ جاهز |
| خريطة الجزيرة | ⏳ ننتظر صورة الجزيرة |
| الشخصيات | ⏳ ننتظر ملفات الشخصيات |
| الأسلحة، الإصابة، المظلة، العاصفة، الغنائم | ⏳ المرحلة القادمة |
| لوبي الأصدقاء بالمعرّف | ⏳ المرحلة القادمة |
| حسابات اللاعبين وقاعدة البيانات | ⏳ لاحقاً |
