# الخرائط

مكان خريطة الجزيرة.

- صورة من فوق للجزيرة تُستخدم **كمرجع** لتوزيع الشاطئ والغابة والتلال والأماكن المهمة.
- أو ملف `.glb` جاهز للجزيرة كاملة.
- أو صورة ارتفاعات (heightmap) بالأبيض والأسود: الأبيض جبل والأسود بحر.

استخدم صوراً من تصميمك أو مسموحاً باستخدامها، وليس خرائط منسوخة من ألعاب أخرى.
