# الشخصيات

ضع هنا ملفات الشخصيات ثلاثية الأبعاد.

- **الصيغة المفضلة:** `.glb` (ملف واحد فيه المجسم والألوان والحركات).
- **مقبول أيضاً:** `.gltf` أو `.fbx`، وسيتم تحويلها إلى `.glb`.
- **الحجم:** أقل من 5 ميغابايت لكل شخصية حتى تفتح اللعبة بسرعة على الهاتف.
- **الحركات المطلوبة لاحقاً:** وقوف، مشي، ركض، قفز، انحناء، إطلاق نار، سقوط.

الصورة العادية (PNG أو JPG) تصلح كمرجع للشكل فقط، ولا تصبح شخصية 3D مباشرة.
