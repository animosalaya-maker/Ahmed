# جزيرة النجاة

لعبة بقاء تعمل في المتصفح على الكمبيوتر والهاتف. افتح `index.html` في أي متصفح.

- **الكمبيوتر:** `WASD` أو الأسهم للحركة، `E` أو المسافة للتفاعل، `C` للصناعة، `Esc` للإيقاف.
- **الهاتف:** اسحب على يسار الشاشة للحركة، وزر ✋ للتفاعل، و🔨 للصناعة.

الهدف: اجمع الخشب والحبال والقماش والمسامير، واصنع حقيبة كبيرة ثم طوفاً، وأبحر بعيداً عن الجزيرة دون أن تأكلك القروش.

`game.html` هو مصدر الصفحة، و`index.html` نسخة كاملة منه للتشغيل المباشر.
